A newspaper front page for Tuesday 17 November 2026, drawn entirely by code: `main.py` (Python 3, standard library only) renders the whole page with its own PNG encoder, its own pixel canvas, its own single-stroke vector font and flat shape illustrations — no image files, no network, no randomness, so every run writes identical bytes. The date runs huge across the masthead; the lead panel covers Ukraine's second day of strikes on the Crimea Bridge, and seven more panels cover Iran's drone strike on the US radar site in Bahrain, Trump in Manila, Japan scrambling jets over Russian aircraft, Nvidia's $116B quarter, the Knesset speaker vote, the Houthi advance on Aden, and the UN debate on a killer-robot ban, with a news ticker along the bottom.

## Run it

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png` (1024×1024).
